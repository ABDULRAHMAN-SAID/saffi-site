# صفّي — موقع الاشتراك (@saffi.om)

موقع ثابت (HTML) فيه 16 لعبة تعليمية، وشخصية «نبراس» التي تجيب من الكتب، ولوحة توليد أسئلة الألعاب من الكتب.

- `index.html` الصفحة الرئيسية ونبراس ولوحة الأسئلة
- `games/` الألعاب (`all.html`) وصورها
- `data/g10/` نص كتب الصف العاشر بعد المسح الضوئي
- `worker-nibras.js` وسيط Cloudflare Worker لربط نبراس بمفتاح الذكاء الاصطناعي (المفتاح يوضع كسرّ `ANTHROPIC_API_KEY` ولا يُكتب في الملفات)

## النشر
Cloudflare Pages: اربط هذا المستودع، بدون أمر بناء، ومجلد الإخراج `/`.
بعد إنشاء الـWorker ضع رابطه في المتغير `NIBRAS_API` داخل `index.html`.
